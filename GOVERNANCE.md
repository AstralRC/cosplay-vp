# Governance and collaborators

## Anyone can contribute

You don't need permission. Fork the repo, make a change, open a pull request. Issues and Discussions are open to everyone.

## Roles

| Role | Can | How to get it |
|---|---|---|
| Contributor | Open issues and pull requests | Anyone |
| Triage collaborator | Label, close and assign issues; review pull requests | 3 merged pull requests or 5 useful benchmark/showcase reports; ask in Discussions |
| Maintainer | Merge pull requests, publish releases, edit settings | Invited by existing maintainers after sustained work |

Maintainers: @idea2547 (Idea, AstralRC). This list grows as people join.

## How decisions are made

- Small changes: one maintainer review and passing checks.
- Changes to the rights and consent rules, licences or project scope: discussed in an issue for at least 7 days first.
- Claims in the docs need a test, a source or a "hypothesis" label.

## Code of conduct

Be kind and specific. Critique work, not people. No harassment, no sexualised content of anyone, no sharing of anyone's footage or personal details without consent. Maintainers can remove content and block accounts that break this. Report problems to the maintainers privately through the email on the AstralRC GitHub profile.
