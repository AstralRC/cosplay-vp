## Submit your work

Open an issue with the **Showcase submission** template, or a pull request adding a row above. Include:

1. A public link (YouTube, TikTok, Instagram, X, Bilibili ...).
2. Which techniques and tools you used, from [Techniques A–Z](techniques.md).
3. One thing that went wrong and how you fixed it. This is the most useful part for other people.
4. Confirmation that:
   - every performer agreed to the post, with guardian consent for anyone under 18;
   - paid work used characters the client owns or licensed;
   - the post is labelled as an ad if it was sponsored.

Fan work of existing characters is welcome as long as it's unpaid and credited. We link to your post; we don't re-host videos.

## Before/after format

The clearest way to show the pipeline: raw phone plate on the left, final on the right, made with `side_by_side`. Add a 3–5 word caption per stage, for example "phone plate → matte → tracked set → cut-in".
