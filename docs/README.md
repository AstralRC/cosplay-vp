# Knowledge base

Open notes on CG cosplay virtual production: putting a real cosplayer, filmed on a phone or camera, inside an Unreal Engine world with anime-style effects. Recorded shots and live event booths are both covered.

Each page says what is established practice and what is still a hypothesis. Pages marked **Hypothesis** have not been benchmarked yet; results from real tests are the most useful contribution you can make.
